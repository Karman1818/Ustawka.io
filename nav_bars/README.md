# Ustawka.io - Flutter Client 🥊

This directory contains the Flutter mobile and web client for **Ustawka.io**.

For full project documentation, architecture overview, and setup instructions, please refer to the main [README.md](../README.md).

## Quick Start

```bash
# Install dependencies
flutter pub get

# Run on Chrome
flutter run -d chrome

# Run as Desktop App on Windows
flutter run -d windows
```
